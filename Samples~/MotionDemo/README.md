# NexUI Motion Demo

This sample covers the production motion building blocks:

- Popup motion through `UIMotionPreset` variants.
- Toast enter/exit motion through screen open/close definitions.
- Gesture feedback with `GestureMotion`.
- Layout motion with `LayoutMotion`.
- Shared element transition data with `SharedElementTransition`.

The included `MotionDemoController` builds a popup preset in code so it can run without pre-authored assets.
