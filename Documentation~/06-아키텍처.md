# 아키텍처

NexUI의 설계 원칙과 각 모듈의 역할.

---

## 계층 구조

```
게임 코드
    │
    ▼
UIManager (Core)          ← 화면 수명·정책·네비게이션. 백엔드를 모름
    │
    ├── Abstractions       ← IUISurface, IUIElementHandle, capability 인터페이스
    ├── State              ← UIStateStore, 바인더, 시그널
    ├── Motion             ← 프리셋, 클립, 플레이어
    ├── Theme              ← 토큰, 레지스트리, 적용자
    └── Components         ← 백엔드 독립 컴포넌트 계약
           │
           ▼
Integrations/*            ← 실제 그래픽 코드. 유일하게 UI Toolkit / uGUI를 참조
    ├── UIToolkit
    ├── UGUI
    ├── DOTween
    └── ...
```

## 황금 규칙

1. **Core는 백엔드 타입을 모른다.** `VisualElement`, `GameObject`, `RectTransform`, `Canvas`를 절대 참조하지 않습니다.
2. **Motion은 capability만 호출한다.** UI Toolkit, uGUI, DOTween을 직접 참조하지 않습니다.
3. **백엔드는 Integrations/*에만 존재합니다.** Core에서 분리되어 있습니다.
4. **파일당 직렬화 클래스 1개.** Unity가 MonoBehaviour를 파일 기준으로 매핑하므로 위반 시 missing script이 발생합니다.

## UIManager

모든 화면의 수명 주기를 소유하는 중앙 오케스트레이터입니다.

### 오픈 흐름

```
OpenAsync("Shop")
  1. 부모 화면 먼저 열기 (relations.parentScreenId)
  2. Queue 정책이면 토스트 큐에 등록
  3. 전환 충돌 확인 (Wait/Cancel/Ignore)
  4. Surface 획득 (retained/pool/새 생성)
  5. ReplaceLayer이면 같은 레이어 형제 닫기 (crossfade)
  6. relations.closes 처리
  7. OnBeforeOpenAsync → 정책 → 오픈 모션 → OnAfterOpenAsync
  8. ScreenOpened 이벤트
```

### 실패 롤백

오픈 중 예외/취소가 발생하면:
- 정책 되돌리기 → 포커스 해제 → 입력 정책 해제 → 스택 제거
- KeepAlive/Pool 인스턴스는 `_retained`에 복원 (파괴하지 않음)
- 새로 생성된 Surface만 파괴

## 컴파일드 엔진 브릿지

Studio 컴파일러가 생성한 `NexScreenProgram`도 UIManager로 열 수 있습니다.

부트스트랩이 등록하는 팩토리:
- `NexCompiledUguiScreenFactory(new UGUIScreenFactory())`
- `NexCompiledUitoolkitScreenFactory(new UIToolkitScreenFactory())`

백엔드 자산이 `NexScreenProgram`이면 컴파일드 빌더로 생성하고, 그 외에는 기존 팩토리로 위임합니다. 두 화면 시스템이 하나의 입구를 공유합니다.

---

## 상태 관리

`UIStateStore`가 단일 진실 공급원(source of truth)입니다.

- **Set**: 값 변경 + 워처 알림 (할당 없음 — 워터마크 방식)
- **Watch**: 변경 구독, Dispose로 해제
- **Derive**: 여러 키 조합 계산값

구독 중 해제해도 스냅샷 의미론이 보장됩니다(해제한 워처도 현재 값은 받음).

## 이벤트 버스

| 이벤트 | 시점 |
|---|---|
| `ScreenOpened` | 오픈 완료 |
| `ScreenClosed` | 클로즈 완료 |
| `ScreenFaulted` | 오픈/클로즈 중 예외 |

MessagePipe/VContainer와 연동하여 게임 전체에 브로드캐스트할 수 있습니다.

## 통합 가이드

### VContainer

```csharp
builder.RegisterInstance(NexUIApp.Manager).AsSelf();
builder.RegisterComponentInHierarchy<UGUIIntegrationBootstrap>();
```

### MessagePipe

`NexUIMessagePublisher`가 ScreenOpened/Closed를 `UIOpenedMessage`/`UIClosedMessage`로 변환합니다.

### Addressables

`loadStrategy = Addressable` 설정 + `resourceKey` 입력.
핸들은 참조 카운팅되어 동시 로드가 안전하고, Surface 파괴 시 자동 해제됩니다.

### Input System

프롬프트 글리프와 디바이스별 반응형 규칙에 `UIInputMode`를 사용합니다.
`manager.InputMode = UIInputMode.Gamepad;` 처럼 설정하면 Studio에서 미리보기 가능합니다.
