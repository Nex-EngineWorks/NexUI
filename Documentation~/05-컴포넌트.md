# 컴포넌트

NexUI가 제공하는 모든 빌트인 uGUI 컴포넌트. 전부 `emiteat.NexUI.Integrations.UGUI` 네임스페이스에 있습니다.

**파일당 직렬화 클래스 1개 규칙**을 준수하므로 프리팹 라운드트립 시 스크립트 참조가 깨지지 않습니다.

---

## 그래픽

| 컴포넌트 | 메뉴 경로 | 설명 |
|---|---|---|
| NXRoundedRect | NexUI/Graphics/NX Rounded Rect | 스프라이트 불필요한 둥근 사각형. 모서리별 반경, 인셋 보더 |
| NXGradient | NexUI/Graphics/NX Gradient | 선형(임의 각도) 또는 4코너 블렌드 그라디언트 |
| NXSoftShadow | NexUI/Graphics/NX Soft Shadow | 여러 겹 페이드 복사본으로 부드러운 드롭 섀도우 |
| NXSegmentedBar | NexUI/Graphics/NX Segmented Bar | HP 핏, 탄약, 실드 등 구분된 바 |
| NXCooldownOverlay | NexUI/Graphics/NX Cooldown Overlay | 방사형 쿨다운 스윕 |

| 컴포넌트 | 설명 |

| NXChoiceList | 단일/복수 선택 리스트. Toggle 기반 옵션 풀 |

## 텍스트 이펙트

공통 베이스: `NXTextBehaviour` — TMP와 Legacy Text 양쪽 자동 감지.

| 컴포넌트 | 설명 |
|---|---|
| NXMarqueeText | 텍스트가 박스보다 길면 가로 스크롤 |
| NXTypewriterText | 한 글자씩 타이핑. 문장부호 일시정지, Skip 지원 |
| NXNumberTicker | 숫자가 목표값으로 부드럽게 카운트업/다운 |

## 오버레이

| 컴포넌트 | 설명 |
|---|---|
| NXModal | 배경 클릭 → CloseRequested 이벤트. 직접 닫지 않고 호출자가 판단 |

## Capability 매핑

각 컴포넌트가 노출하는 런타임 capability:

| Capability | 제공 컴포넌트 예시 |
|---|---|
| IUITextCapability | Label, Button, TMP_Text |
| IUIValueCapability | ProgressBar, Slider, NXSegmentedBar, NXRadialFill |
| IUIVisibilityCapability | 모든 VisualElement |
| IUITransformCapability | 모든 VisualElement (opacity/pos/scale/rot) |
| IUIColorCapability | Graphic 계열 |
| IUIInteractableCapability | Button, Slider, Selectable |
| IUIClickCapability | Button |
| INXRadialFill / INXSpinner / ... | 대응하는 NX* 인터페이스 |

Core 코드는 capability만 호출하므로 백엔드 전환(uGUI ↔ UIToolkit) 시 무수정입니다.
