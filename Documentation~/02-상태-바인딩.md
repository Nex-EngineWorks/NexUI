# 상태 바인딩

UI 요소를 게임 데이터에 연결하는 시스템. `UIStateStore`에 값을 넣으면 바인딩된 모든 UI가 자동 업데이트됩니다.

---

## 핵심 개념

```
게임 코드 ──▶ UIStateStore.Set("player.hp", 80f)
                        │
                        ▼ (자동 알림)
              ProgressBar.value = 80f
```

Studio에서 요소의 **Binding** 섹션에 키를 입력하면 런타임에 자동으로 연결됩니다.

---

## UIStateStore 기본

```csharp
// 값 쓰기
store.Set("player.hp", 80f);
store.Set("player.name", "김철수");
store.Set("player.isAlive", true);

// 값 읽기
float hp = store.Get<float>("player.hp");
string name = store.Get<string>("player.name");

// 구독 — 값이 변경될 때마다 호출
var sub = store.Watch<float>("player.hp", value =>
{
    Debug.Log($"HP changed: {value}");
});

// 구독 해제
sub.Dispose();
```

## 6개 바인딩 채널

Studio 인스펙터의 Binding 섹션에서 설정합니다.

| 채널 | 필드 | 대상 capability | 예시 |
|---|---|---|---|
| Text | `textKey` | `IUITextCapability` | `"player.name"` → Label.text |
| Value | `valueKey` | `IUIValueCapability` | `"player.hp"` → Slider/ProgressBar 값 |
| Visibility | `visibilityKey` | `IUIVisibilityCapability` | `"inventory.isOpen"` → 요소 표시/숨김 |
| Class | `classKey` | `IUIStyleCapability` | `"item.selected"` → CSS 클래스 토글 |
| Command | `commandKey` | 클릭 이벤트 | `"shop.buy"` → 커맨드 디스패치 |
| Interactable | `interactableKey` | `IUIInteractableCapability` | `"shop.canBuy"` → 버튼 활성화 |

### Studio에서 설정

1. 캔버스에서 요소 선택
2. Inspector > Binding 섹션
3. 원하는 채널에 키 입력 (예: `textKey = player.name`)
4. Save

### 런타임에서 값 변경

```csharp
// 게임 코드 어디서든:
NexUIApp.Manager.State.Set("player.name", "새 이름");
// → textKey = "player.name"으로 바인딩된 모든 Label이 즉시 업데이트
```

## 커맨드 바인딩

요소를 클릭하면 `commandKey`에 해당하는 커맨드가 디스패치됩니다.

```csharp
// 1. 핸들러 등록 (부트스트랩 후 한 번만)
dispatcher.RegisterHandler<BuyItemCommand>(new BuyItemHandler());

// 2. Studio에서 Button의 commandKey = "shop.buy" 설정

// 3. 유저가 클릭 → BuyItemCommand 디스패치 → BuyItemHandler 실행
```

## 양방향 바인딩

TextField, Slider 등 입력 컴포넌트는 역방향 전파를 지원합니다.

```csharp
// UI에서 유저가 값을 변경하면 스토어에 자동 반영
// (Studio에서 Two-Way 체크박스 활성화 필요)
```

## 파생 상태 (Derived State)

여러 키를 조합한 계산값:

```csharp
store.Derive("player.hpPercent",
    new[] { "player.hp", "player.maxHp" },
    values =>
    {
        var hp = (float)values[0];
        var max = (float)values[1];
        return max > 0 ? hp / max : 0f;
    });
```

`player.hp` 또는 `player.maxHp`가 변경되면 `player.hpPercent`가 자동 재계산되고,
이를 watch하는 UI도 연쇄 업데이트됩니다.

---

## 성능

- `Set()`은 스냅샷 배열을 할당하지 않습니다. 워터마크 + 지연 제거 방식이라 매 프레임 HP 업데이트도 GC 압박이 없습니다.
- 구독 중 해제(unsubscribe during dispatch)도 정확히 처리됩니다.
