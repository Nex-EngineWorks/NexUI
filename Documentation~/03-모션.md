# 모션

화면과 요소에 애니메이션을 적용하는 시스템. 프리셋 기반 간단 모션과 키프레임 클립 두 가지 방식을 지원합니다.

---

## 프리셋 기반 (간단)

`UIMotionPreset` 에셋으로 오픈/클로즈 애니메이션을 정의합니다.

### 설정

1. `Create > NexUI > Motion Preset`
2. 인스펙터에서 스텝 추가:

| 필드 | 설명 |
|---|---|
| Property | Opacity / PositionX / PositionY / ScaleX / ScaleY / Rotation |
| From | 시작값 |
| To | 종료값 |
| Duration | 지속 시간(초) |
| Delay | 시작 지연(초) |
| Easing | Linear / EaseInOut |

3. 화면 정의의 `motion.openMotion` 또는 요소의 Motion 섹션에 할당

### 동작

```csharp
// 화면 열기 → openMotion 자동 재생
await NexUIApp.OpenAsync("Shop");

// 화면 닫기 → closeMotion 자동 재생
await NexUIApp.CloseAsync("Shop");
```

프리셋 예시 — 페이드 인:
```
Property: Opacity, From: 0, To: 1, Duration: 0.3, Easing: EaseInOut
```

## 모션 클립 (키프레임 타임라인)

여러 요소 × 여러 프로퍼티를 하나의 타임라인에서 애니메이트합니다.

### 생성

1. `Tools > Nex/NexUI Studio > Motion Clip Editor`
2. **Create Clip** 클릭
3. 캔버스에서 대상 요소 선택 → **Add Track**
4. 타임라인에서 우클릭 → **Add Key** (또는 Auto Key 활성화 후 속성 변경)
5. Save

### 구조

```
UIMotionClip
  ├── Track 1: "play_button" → Opacity
  │     ├── Key(0.0s, opacity=0)
  │     ├── Key(0.3s, opacity=1)
  │     └── Key(0.5s, opacity=1)   ← hold
  ├── Track 2: "panel" → PositionY
  │     ├── Key(0.0s, y=-200)
  │     └── Key(0.4s, y=0)
  └── Track 3: "title" → ScaleX/Y
        └── ...
```

### 재생

```csharp
// 특정 화면에 클립 적용
await manager.PlayMotionClipAsync("Shop", myMotionClip);

// 취소하면 마지막 포즈로 스냅 (반쯤 사라진 상태로 남지 않음)
```

## 백엔드별 플레이어

| 플레이어 | 의존성 | 특징 |
|---|---|---|
| BuiltInMotionPlayer | 없음 | unscaled time, 모든 이징 지원 |
| DOTweenMotionPlayer | DOTween | 더 부드러운 이징, Sequence 최적화 |

부트스트랩이 기본으로 BuiltIn을 등록합니다. DOTween 사용 시:

```csharp
manager.MotionPlayer = new DOTweenMotionPlayer();
```

DOTween 플레이어는 모든 키프레임 세그먼트를 재생하며, 취소 시 종료 포즈로 스냅합니다.

## 크로스페이드 (ReplaceLayer)

`ReplaceLayer` 정책 화면이 열리면:

1. 새 화면의 **오픈 모션** 시작
2. **동시에** 기존 화면들의 **클로즈 모션**도 병렬 재생
3. 양쪽 완료 후 OnAfterOpen 발생

이전에는 exit가 skip되었지만 이제 crossfade가 기본 동작입니다.

## 모션 그래프 & 스테이트 머신

고급 시나리오:

- **Motion Graph**: 클립 간 전환 관계를 노드 그래프로 편집
- **Motion State Machine**: 상태별 클립 + 전환 조건 정의
- **Trigger Bindings**: 클릭/호버/커맨드에 모션 연결

모두 `Tools > Nex/NexUI Studio` 메뉴에서 접근합니다.
