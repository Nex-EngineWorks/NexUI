# Project setup

The Project Setup tool creates settings, registries, starter themes, motions and screen
definitions under `Assets/NexUI`.

Use Designer's `Tools > NexUI > Utilities > Setup Doctor` before and after setup. The doctor is
read-only until you press an explicit action button; it reports missing assets, missing screen
definitions and missing scene bootstraps.

Generated project assets belong under `Assets/`, not inside an installed read-only package.
