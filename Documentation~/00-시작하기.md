# 시작하기

NexUI는 Unity 런타임 UI 프레임워크입니다. 같은 게임 코드로 UI Toolkit과 uGUI 양쪽을 구동합니다.

이 문서를 끝까지 따라 하면 화면을 열고, 데이터를 전달하고, 결과를 받을 수 있습니다.

---

## 설치

1. `com.nexengineworks.nexui` 패키지를 `Packages/manifest.json`에 추가:

```json
{
  "dependencies": {
    "com.nexengineworks.nexui": "file:../Packages/com.nexengineworks.nexui"
  }
}
```

2. Unity 에디터 재시작. 컴파일 오류가 없으면 성공.
3. (선택) Studio 시각 편집기: `com.nexengineworks.nexui.studio`도 동일하게 추가.

필요한 최소 Unity 버전: **2022.3 LTS**

외부 의존성 없음. `System.Threading.Tasks`만 사용하므로 설치 즉시 컴파일됩니다.

---

## 부트스트랩

씬에 백엔드별 부트스트랩 컴포넌트를 하나 배치합니다. 둘 중 하나만 있으면 됩니다.

| 백엔드 | 컴포넌트 | 함께 배치할 것 |
|---|---|---|
| UI Toolkit | `UIToolkitIntegrationBootstrap` | `UIDocument` |
| uGUI | `UGUIIntegrationBootstrap` | `Canvas` |

부트스트랩이 Awake에서 자동으로 등록하는 것:
- 화면 팩토리
- 포커스 어댑터
- 테마 적용자
- 빌트인 모션 플레이어
- 레이어 컨테이너 6개 (Background / HUD / Window / Modal / Toast / Overlay)

게임 코드에서 추가 설정은 필요 없습니다.

## 첫 화면 열기

### 1. UIScreenDefinition 생성

`Create > NexUI > Screen Definition`

인스펙터에서 설정:

| 필드 | 값 |
|---|---|
| Screen Id | `HUD` |
| Layer Type | `HUD` |
| Open Policy | `Additive` |
| Backend | `uGUI` |
| Asset | 프리팹 또는 UXML 참조 |

### 2. 코드로 등록 + 열기

```csharp
using emiteat.NexUI.Core;
using UnityEngine;

public class GameBootstrap : MonoBehaviour
{
    [SerializeField] private UIScreenDefinition hudScreen;

    private void Start()
    {
        NexUIApp.RegisterScreen(hudScreen);
        _ = OpenHud();
    }

    private async void OpenHud()
    {
        await NexUIApp.OpenAsync("HUD");
        Debug.Log("HUD opened!");
    }
}
```

이것으로 끝입니다. `OpenAsync`가 내부적으로 다음을 처리합니다:

1. 팩토리에서 Surface 생성
2. 레이어에 마운트 + 정렬 순서 적용
3. `OnBeforeOpenAsync` → 정책(커서/timeScale) → 오픈 모션 → `OnAfterOpenAsync`
4. `ScreenOpened` 이벤트 발생

---

## 닫기

```csharp
await NexUIApp.CloseAsync("HUD");
```

닫힘 흐름: `OnBeforeCloseAsync` → 클로즈 모션 → 정책 되돌리기 → 포커스 해제 → 스택/모달 제거 → retain 또는 destroy → `OnAfterCloseAsync` → `ScreenClosed`

KeepAlive나 Pool 정책이면 인스턴스가 파괴되지 않고 재사용 대기 상태가 됩니다.

## 데이터 전달하고 결과 받기

화면을 열 때 데이터를 넣고, 닫힐 때 결과를 받을 수 있습니다.

### 열면서 데이터 전달

```csharp
await NexUIApp.OpenAsync("Shop", new UIOpenArgs
{
    payload = new System.Collections.Generic.Dictionary<string, object>
    {
        { "tab", "weapon" },
        { "gold", 1500 }
    },
    variantId = "compact"   // 선택적 변형
});
```

화면의 라이프사이클에서 수신:

```csharp
public class ShopScreen : MonoBehaviour, IUIScreenLifecycle
{
    public UniTask OnBeforeOpenAsync(UIScreenContext ctx)
    {
        // ctx.Payload에서 데이터 꺼내기
        if (ctx.Payload != null && ctx.Payload.TryGetValue("tab", out var tab))
            Debug.Log($"Opening tab: {tab}");

        return UniTask.CompletedTask;
    }
}
```

### 닫힐 때 결과 반환

```csharp
// Shop 화면을 닫는 쪽:
await NexUIApp.CloseAsync("Shop", new UICloseArgs { result = "sword_042" });
```

### 기다리는 쪽:

```csharp
await NexUIApp.OpenAsync("Shop");
var result = await NexUIApp.WaitForCloseAsync("Shop");
Debug.Log($"User purchased: {result}");   // "sword_042"
```

이미 닫힌 화면을 기다리면 마지막 결과가 즉시 반환됩니다. 데드락 없습니다.

## 취소

열기/닫기/프리로드에 `CancellationToken`을 넘길 수 있습니다:

```csharp
var cts = new CancellationTokenSource();

// 취소되면 진행 중인 오픈이 롤백됨
var openTask = NexUIApp.OpenAsync("Loading", cancellationToken: cts.Token);

// 5초 후 취소
cts.CancelAfter(5000);

try { await openTask; }
catch (OperationCanceledException) { Debug.Log("Open cancelled"); }
```
