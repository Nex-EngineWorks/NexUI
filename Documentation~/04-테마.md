# 테마

색상, 폰트 크기, 간격 등을 토큰으로 관리하고 런타임에 전환하는 시스템.

---

## 토큰 정의

`Create > NexUI > Theme`

| 필드 | 예시 |
|---|---|
| themeId | `"dark"` |
| tokens | `color.primary = #4A9EFF`, `color.background = #1A1A2E`, `font.size.body = 14`, `spacing.md = 16` |

여러 테마를 등록하면 런타임에 전환할 수 있습니다.

```csharp
// 등록
NexUITheme.Registry.Register(darkTheme);
NexUITheme.Registry.Register(lightTheme);

// 전환
NexUITheme.Use("light");
```

전환하면 **열려 있는 모든 화면**에 즉시 적용됩니다. 이후 열리는 화면에도 자동 적용됩니다.

---

## 토큰 오버라이드 (런타임)

특정 토큰만 일시적으로 변경:

```csharp
NexUITheme.SetToken("color.primary", "#FF6B6B");

// 되돌리기
NexUITheme.Overrides.ClearOverrides();
```

토큰 변경도 열린 모든 화면에 즉시 반영됩니다.

---

## 요소별 토큰 오버라이드

개별 요소에만 토큰을 덮어쓸 수 있습니다.

Studio: Inspector > Theme 섹션 > Token Overrides
- Key: `color.primary`
- Value: `#FF0000`

이 요소만 빨간색이 되고 다른 요소는 공유 테마를 따릅니다.

---

## 스타일 클래스

테마와 별개로 요소에 클래스를 붙여 스타일을 전환할 수 있습니다.

```csharp
// Studio에서 Style > Classes에 "selected" 추가
// USS(UIToolkit) 또는 컴포넌트(uGUI)에서 .selected 스타일 정의

// 런타임:
store.Set("item.selected", "true");
// → classKey = "item.selected" 바인딩된 요소에 클래스 토글
```

---

## 반응형 규칙

해상도/입력 모드에 따라 토큰이나 속성을 자동 변경:

```csharp
var rules = new ResponsiveRuleSet();
rules.Add(new ResponsiveRule
{
    name = "wide",
    minWidth = 1280,
    overrides = new[] { new ThemeToken { key = "spacing.md", value = "24" } }
});
rules.Apply(Screen.width, NexUIThemeAPI.Overrides);
```

Studio에서는 `Tools > Responsive Rules` 에디터로 시각적으로 편집합니다.

## 백엔드 적용자

부트스트랩이 자동 등록합니다:

| 백엔드 | 적용자 | 방식 |
|---|---|---|
| UI Toolkit | `UIToolkitThemeApplier` | USS 커스텀 프로퍼티 / 인라인 스타일 |
| uGUI | `UGUIThemeApplier` | Image.color, TMP_Text.fontSize 등 |

Core는 테마 모듈을 참조하지 않습니다. `UIOpenSurfaceRegistry` 브릿지로 열린 Surface를 찾아 적용합니다.
