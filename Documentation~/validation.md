# Validation

Run validation before committing generated assets and before every release build.

- Setup Doctor checks installation and project readiness.
- Core Validator checks screen definitions, registries, motions, themes and command setup.
- Designer Validation checks metadata hierarchy, backend support and authoring references.
- Designer Save Report lists changed, skipped, warning and error results.

A clean validation report does not replace Play Mode and Player build verification because
runtime keys, fonts, input, layout and platform capabilities can only be confirmed there.
