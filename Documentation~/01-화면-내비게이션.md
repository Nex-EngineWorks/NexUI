# 화면 내비게이션

화면을 여닫고, 스택으로 관리하고, 데이터를 주고받는 모든 방법.

---

## 기본 API

```csharp
var ui = NexUIApp.Manager;   // 또는 NexUIApp static 메서드 직접 사용

// 열기
await NexUIApp.OpenAsync("Shop");

// 닫기
await NexUIApp.CloseAsync("Shop");

// 토글 (열려있으면 닫고, 닫혀있으면 엶)
await NexUIApp.ToggleAsync("Shop");

// 뒤로가기 (스택에서 팝)
await NexUIApp.BackAsync();
```

---

## Open Policy

`UIScreenLayerConfig.openPolicy`로 화면이 열릴 때 같은 레이어의 다른 화면과 어떻게 상호작용할지 결정합니다.

| 정책 | 동작 |
|---|---|
| `Additive` | 기존 화면 유지, 위에 추가 |
| `ReplaceLayer` | 같은 레이어의 모든 화면을 닫고 열기 (exit 모션 재생 후 enter) |
| `Single` | 이미 열려 있으면 무시 (포커스만) |
| `StackPush` | Back 스택에 푸시. `BackAsync()`로 닫기 가능 |
| `Queue` | 한 번에 하나씩 순차 표시 (토스트 스타일). 이전 것이 닫히면 자동으로 다음 것 열림 |

### 예제: ReplaceLayer

```csharp
// Settings 화면 정의:
// layerType = Window, openPolicy = ReplaceLayer

await NexUIApp.OpenAsync("AudioSettings");   // AudioSettings 열림
await NexUIApp.OpenAsync("VideoSettings");   // AudioSettings가 exit 모션과 함께 닫히고 VideoSettings가 crossfade로 열림
```

## 뒤로가기

`StackPush` 정책으로 열린 화면은 백 스택에 쌓입니다.

```csharp
// Page1 → Page2 → Page3 순서로 StackPush 열기
await NexUIApp.OpenAsync("Page1");
await NexUIApp.OpenAsync("Page2");
await NexUIApp.OpenAsync("Page3");

// 뒤로가기: Page3가 닫힘
await NexUIApp.BackAsync();
```

**결과와 함께 뒤로가기:**

```csharp
await NexUIApp.BackAsync<MyResult>(result);
```

모달 폴백: 백 스택이 비어 있으면 최상위 Modal 중 `closeOnBack = true`인 것을 닫습니다.

## 결과값 (Request/Response 패턴)

화면을 열고 닫힐 때 값을 받는 패턴입니다. 아이템 선택, 확인 다이얼로그 등에 사용합니다.

```csharp
// 1. 아이템 선택 화면 열기
await NexUIApp.OpenAsync("ItemPicker", new UIOpenArgs
{
    payload = new Dictionary<string, object> { { "filter", "epic" } }
});

// 2. 닫힘 대기 + 결과 수신
var picked = await NexUIApp.WaitForCloseAsync("ItemPicker");

if (picked != null)
    Debug.Log($"선택된 아이템: {picked}");
else
    Debug.Log("취소됨");
```

닫는 쪽:

```csharp
// 확정 버튼
await NexUIApp.CloseAsync("ItemPicker", new UICloseArgs { result = "sword_042" });

// 취소 버튼 — result를 넣지 않으면 null 전달
await NexUIApp.CloseAsync("ItemPicker");
```

이미 닫힌 화면을 `WaitForCloseAsync`하면 **마지막 결과가 즉시 반환**됩니다. 데드락 없음.

뒤로가기도 결과를 운반할 수 있습니다:

```csharp
await NexUIApp.BackAsync<string>("cancelled");
```

## 일괄 종료

```csharp
// 모든 열린 화면 닫기 ("로비로 돌아가기")
await NexUIApp.CloseAllAsync();

// 특정 레이어만 닫기 ("팝업 전부 닫기")
await NexUIApp.CloseLayerAsync(UILayerType.Modal);

// 하나만 남기고 전부 닫기 ("HUD에 집중")
await NexUIApp.CloseOthersAsync("HUD");
```

일괄 종료는 스냅샷 우선 방식이라 relations(`opensWith`, `closes`)이 중간에 발동해도 안전합니다.

---

## 스택 스냅샷 / 복원

게임 종료 시점의 화면 상태를 저장하고, 재시작 후 복원합니다.

```csharp
// 종료 직전: 현재 상태 캡처
var snapshot = NexUIApp.CaptureStackSnapshot();

// ... 게임 재시작 ...

// 복원: 전부 닫고 → 캡처 순서대로 다시 열기
await NexUIApp.RestoreStackAsync(snapshot);
```

- StackPush 화면은 복원 시 자동으로 백 스택에 재푸시됩니다.
- Modal은 자동으로 모달 스택에 재푸시됩니다.
- payload는 참조 보관이므로 프로세스 내 세션 복원에 적합합니다. 도메인 리로드 간에는 id/variant만 유지됩니다.

## 충돌 정책

같은 화면에 대해 Open/Close가 동시에 요청될 때 동작을 결정합니다.

| 정책 | 동작 |
|---|---|
| `Wait` | 기존 전환 완료 후 실행 (기본값) |
| `Cancel` | 기존 전환 취소 + 즉시 실행. 취소된 오픈은 롤백되고 KeepAlive 인스턴스는 보존 |
| `Ignore` | 새 요청 드롭 |

```csharp
screen.policy.conflictPolicy = UITransitionConflictPolicy.Cancel;
```

## 생명주기 콜백

`IUIScreenLifecycle`을 구현한 컴포넌트를 프리팹에 붙이면 자동 호출됩니다:

| 콜백 | 시점 |
|---|---|
| `OnBeforeOpenAsync(ctx)` | Surface 활성화 직후, 정책 적용 전 |
| `OnAfterOpenAsync(ctx)` | 오픈 모션 완료 후 |
| `OnBeforeCloseAsync(ctx)` | 클로즈 모션 시작 전 |
| `OnAfterCloseAsync(ctx)` | 정리 완료 후 |

`ctx`에서 사용 가능: `ctx.ScreenId`, `ctx.Surface`, `ctx.CancellationToken`, `ctx.Payload`, `ctx.VariantId`
